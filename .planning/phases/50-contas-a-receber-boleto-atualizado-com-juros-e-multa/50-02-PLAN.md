Regra de `decidirValoresBaixaFixos` (tudo em centavos inteiros):
```text
base_i = principal_i + juros_i + multa_i ; base = soma(base_i)
1. valorPagoEfi nulo                       -> ok, valores do snapshot (valorPago_i = base_i)
2. |efi - base| <= tolerancia (0,10)        -> ok, valores do snapshot
3. posVencimento presente, dataPagamento > posVencimento.vencimento e efi > base:
     dias = diasEntre(posVencimento.vencimento, dataPagamento)
     multaMax = floor((base * round(multaPercentual*100) + 5000) / 10000)
     jurosMax = floor((base * round(taxaJurosMes*1000/30) * dias + 50000) / 100000)
     excedente = efi - base
     excedente <= multaMax + jurosMax + tolerancia ->
        multaExtra = min(excedente, multaMax) ; jurosExtra = excedente - multaExtra
        cada extra repartido por titulo: round(extra * base_i / base) para todos menos o ultimo; o ultimo recebe o resto
        juros_i += jurosExtra_i ; multa_i += multaExtra_i ; atraso_i += dias ; valorPago_i = principal_i + juros_i + multa_i
        -> ok (soma de valorPago_i = efi exatamente)
4. qualquer outro caso                      -> { ok: false, codigo: "VALOR_INCOMPATIVEL", mensagem com efi, base e (quando houver) teto }
```
Caso numérico de referência (1 título, conferido à mão): base 1022,64 (1000 + 2,64 + 20,00, atraso 8), novo vencimento V, pago em V+2 com taxas pós-vencimento 0,99/2 -> multaMax 20,45, jurosMax 0,67; EFI 1043,76 -> juros 3,31, multa 40,45, atraso 10, valorPago 1043,76; EFI 1100,00 -> VALOR_INCOMPATIVEL.
