### Sequencia de SQL da baixa (literais fixos; apenas valores via $n; PostgreSQL 9.0.5)

```sql
-- 1) leitura/trava (FOR UPDATE somente quando simular for falso)
SELECT cr.idcontareceber, cr.idcliente, cr.numerotitulo, cr.valor,
       to_char(cr.datavencimento, 'YYYY-MM-DD') AS datavencimento, TRIM(cr.statusconta) AS statusconta
  FROM conta_receber cr WHERE cr.idcontareceber = ANY($1::int[]) ORDER BY cr.idcontareceber FOR UPDATE;

-- 2) nome do cliente (mesma regra de AthosService.buscarDadosClienteContasReceber)
SELECT COALESCE(cf.nome, cj.nomefantasia, cj.razaosocial, 'Cliente ' || c.idcliente::text) AS nome_cliente
  FROM cliente c LEFT JOIN cliente_fisico cf ON cf.idcliente = c.idcliente
  LEFT JOIN cliente_juridico cj ON cj.idcliente = c.idcliente WHERE c.idcliente = $1;

-- 3) por titulo ainda nao REC
INSERT INTO conta_recebida (idcontareceber, valorpago, valortroco, datapagamento, horapagamento, juros, desconto,
                            atraso, idfuncionariousuario, idformapagamento, multa, idcondicaopagamento)
VALUES ($1, $2, 0, $3::timestamp, cast(current_time(0) as time), $4, 0, $5, $6, $7, $8, NULL)
RETURNING idcontarecebida;
INSERT INTO livro_registro_io (idlivroregistro, idfuncionario, datalancamento, horalancamento, descricao,
                               valorentrada, tipopagamento, idcontarecebida)
VALUES ($1, $2, $3::date, cast(current_time(0) as time), $4, $5, '', $6);
UPDATE conta_receber SET statusconta = 'REC' WHERE idcontareceber = $1;
UPDATE boleto SET statusboleto = 'REC' WHERE idcontareceber = $1;   -- zero linhas afetadas e valido

-- 4) uma vez ao fim, se ao menos um titulo foi baixado
UPDATE cliente SET aviso1 = false, aviso2 = false, aviso3 = false WHERE idcliente = $1;

-- 5) somente baixa retroativa, por titulo baixado
INSERT INTO log (idfuncionariousuario, data, hora, mensagem) VALUES ($1, current_date, cast(current_time(0) as time), $2);
```

Simulacao: `BEGIN` seguido de `SET TRANSACTION READ ONLY`, SELECT 1 e 2 sem FOR UPDATE, calculo dos valores, `ROLLBACK`; nenhuma das instrucoes 3, 4 e 5 e emitida.
