<objective>
Entregar o estorno ("Voltar Contas Recebidas") com as mesmas garantias da baixa, os controles de baixa manual e estorno no painel de boletos e o roteiro de verificacao guiada que o usuario executara no Athos real, porque nenhuma automacao pode escrever la (D-07).

Purpose: D-06 inclui o estorno na fase, e sem ele uma baixa errada exigiria mexer no Athos a mao. Como o Athos nao tem rollback por comando, o estorno so apaga o que o proprio Sistema gravou (ids registrados na trilha), em uma transacao, com confirmacao explicita e simulacao somente leitura. O roteiro fecha a fase: nenhum teste automatizado prova que o SQL se comporta como a tela do Athos; quem prova e o usuario, com backup e passo a passo.

Output: `estornarBaixa` no servico Athos, `estornarBaixa` no orquestrador, `POST /cobranca/boleto/:id/estornar-baixa-athos`, duas rotas proxy Next, coluna e botoes no painel, e `43-ROTEIRO-VERIFICACAO-MANUAL.md`.
</objective>

### Sequencia de SQL do estorno (literais fixos; valores por $n; PostgreSQL 9.0.5)

```sql
-- 1) leitura/trava (FOR UPDATE somente fora da simulacao)
SELECT cr.idcontareceber, cr.idcliente, cr.valor, to_char(cr.datavencimento, 'YYYY-MM-DD') AS datavencimento,
       TRIM(cr.statusconta) AS statusconta
  FROM conta_receber cr WHERE cr.idcontareceber = ANY($1::int[]) ORDER BY cr.idcontareceber FOR UPDATE;
SELECT rec.idcontarecebida, rec.idcontareceber, rec.valorpago
  FROM conta_recebida rec WHERE rec.idcontareceber = ANY($1::int[]) ORDER BY rec.idcontareceber, rec.idcontarecebida;

-- 2) por titulo, na ordem do Athos (43-REFERENCIA-SQL-ATHOS.md, secao Estorno)
DELETE FROM livro_registro_io WHERE idcontarecebida = $1;
DELETE FROM caixa_entrada WHERE idcontarecebida = $1;
DELETE FROM caixa_movimento_recebimento WHERE idcontareceber = $1;
DELETE FROM conta_recebida WHERE idcontareceber = $1;
DELETE FROM cliente_cartao_preferencial WHERE descricaolancamento ~ $1;   -- $1 = 'BAIXA CONTA RECEBER(.*[^0-9])?' || id || '([^0-9]|$)', montado em JS com id inteiro validado
UPDATE conta_receber SET statusconta = $2 WHERE idcontareceber = $1;       -- $2 = 'VEN' se datavencimento menor que hoje, senao 'AVC'
INSERT INTO log (idfuncionariousuario, mensagem, data, hora) VALUES ($1, $2, current_date, cast(current_time(0) as time));
-- mensagem: 'Voltou a conta recebida: <idcontareceber> Valor: R$ <principal> Valor Pago: R$ <valorpago>' (virgula decimal, sem milhar; so ASCII)
```

Validacoes antes de qualquer DELETE: lista nao vazia e sem ids repetidos; todos os titulos existem (TITULO_NAO_ENCONTRADO) e pertencem a idclienteAthos (CLIENTE_DIVERGENTE); statusconta igual a REC (STATUS_INVALIDO); exatamente um recebimento por titulo (RECEBIMENTO_NAO_ENCONTRADO para zero, RECEBIMENTO_DIVERGENTE para mais de um ou para idcontarecebida diferente do informado).
