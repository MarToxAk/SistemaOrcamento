### `AthosService.buscarNomesClientes` (NOVO — `apps/backend/src/modules/integrations/athos/athos.service.ts`)

```typescript
async buscarNomesClientes(idclientes: number[]): Promise<Array<{ idcliente: number; nome_cliente: string }>>
```

SQL (uma unica consulta, parametrizada, sem interpolacao de string):

```sql
SELECT c.idcliente,
  COALESCE(cf.nome, cj.nomefantasia, cj.razaosocial, 'Cliente #' || c.idcliente::text) AS nome_cliente
FROM cliente c
LEFT JOIN cliente_fisico cf ON cf.idcliente = c.idcliente
LEFT JOIN cliente_juridico cj ON cj.idcliente = c.idcliente
WHERE c.idcliente = ANY($1)
```

Regras: sanitizar a entrada com `Number.isInteger(n) && n > 0` antes da consulta; se a lista sanitizada ficar vazia retornar `[]` sem abrir conexao; envolver em `pool.connect()` / `try { ... } catch { logger.warn; return [] } finally { client.release(); }` — mesmo formato de `buscarDadosClienteContasReceber` (athos.service.ts:1115-1155).

### `CobrancaService.buscarBoletosDashboard` (NOVO — `apps/backend/src/modules/cobranca/cobranca.service.ts`)

```typescript
type NfseStatusBoleto = "completa" | "parcial" | "pendente";

async buscarBoletosDashboard(): Promise<Array<{
  id: number;
  idclienteAthos: number;
  nomeCliente: string;
  status: string;              // "pendente" | "pago"
  valor: number;
  expireAt: string | null;     // "YYYY-MM-DD"
  diasParaVencer: number | null;
  linkBoleto: string | null;
  criadoEm: Date;
  titulos: number[];           // idcontareceber
  nfseStatus: NfseStatusBoleto;
}>>
```

Consulta Prisma base (analogo exato: `buscarBoletosCliente`, cobranca.service.ts:794-798, sem o filtro `where: { idclienteAthos }`):

```typescript
const boletos = await this.prisma.cobrancaBoleto.findMany({
  where: { status: { not: "cancelado" } },
  orderBy: { criadoEm: "desc" },
  include: { titulos: { select: { idcontareceber: true } } },
});
```

`diasParaVencer` = `Math.round((Date.parse(expireAt + "T00:00:00Z") - Date.parse(hojeISO + "T00:00:00Z")) / 86400000)` com `hojeISO = new Date().toISOString().slice(0, 10)`; `null` quando `expireAt` e nulo ou nao parseavel. Negativo = vencido.

Ordenacao final do array retornado: `expireAt` ascendente (comparacao lexicografica funciona — `expireAt` e sempre `YYYY-MM-DD`, validado por `@IsDateString()` em `CriarBoletoDto`), com `expireAt === null` sempre por ultimo.

### Proxy Next.js (NOVO — `apps/frontend/src/app/api/cobranca/boleto/dashboard/route.ts`)

```typescript
import { type NextRequest, NextResponse } from "next/server";

import { backendFetch } from "@/lib/backend-client";
import { requireAdminSession } from "@/lib/admin-session";

export async function GET(req: NextRequest) {
  if (!requireAdminSession(req)) {
    return NextResponse.json({ error: "Nao autorizado." }, { status: 401 });
  }
  try {
    const res = await backendFetch("/cobranca/boleto/dashboard", { method: "GET" });
    const data = await res.json().catch(() => ({ error: "Resposta inválida do backend." }));
    if (!res.ok) return NextResponse.json(data, { status: res.status });
    return NextResponse.json(data);
  } catch {
    return NextResponse.json({ error: "Falha ao conectar no backend." }, { status: 500 });
  }
}
```
