<objective>
Entregar a lista fixa de CC por cliente (D-06) combinada com a edição a cada envio (D-01): persistência em tabela Prisma própria, endpoints autenticados de leitura/gravação, pré-preenchimento do modal e gravação opt-in pelo checkbox "Salvar como padrão deste cliente".

Purpose: o plano 42-01 já provou o CC ponta a ponta (modal -> SMTP -> histórico). Este plano expande a fatia com a memória por cliente, para o operador não redigitar os mesmos e-mails de cópia a cada cobrança, sem que um CC pontual vire permanente.

Output: model `CobrancaEmailCcPadrao` + migration idempotente; `SalvarCcPadraoDto`; `EmailEnvioService.buscarCcPadrao` / `salvarCcPadrao` (reutilizando `normalizarListaCc` de 42-01); rotas `GET`/`PUT /cobranca/email/cc-padrao/:idclienteAthos`; proxy Next com `requireAdminSession`; pré-preenchimento + checkbox no modal.

Requisitos locais cobertos (tabela completa em 42-01-PLAN.md): CC-05 (lista fixa por cliente), CC-01 (edição a cada envio sobre a lista pré-preenchida), CC-02 (mesma normalização aplicada à lista salva).

Nota de decomposição: o tracer de 42-01 já atravessou todas as camadas; aqui a fatia "lista fixa" é dividida em backend (Task 1, contrato HTTP verificável por Jest/ValidationPipe) e tela (Task 2) apenas por tamanho — a fatia vertical completa (DB -> HTTP -> proxy -> modal) somaria 8 arquivos numa única task.

### Service (`apps/backend/src/modules/cobranca/email-envio.service.ts`)

```typescript
async buscarCcPadrao(idclienteAthos: number): Promise<{ idclienteAthos: number; emails: string[] }>;
async salvarCcPadrao(idclienteAthos: number, emails: readonly string[]): Promise<{ idclienteAthos: number; emails: string[] }>;
```

- Ambos validam `Number.isInteger(idclienteAthos) && idclienteAthos > 0`, senão `BadRequestException("idclienteAthos inválido.")` sem tocar no Prisma.
- `buscarCcPadrao`: `this.prisma.cobrancaEmailCcPadrao.findUnique({ where: { idclienteAthos } })` -> `emails: row?.emails ?? []`.
- `salvarCcPadrao`: `const lista = normalizarListaCc(emails)` (sem principal) -> `this.prisma.cobrancaEmailCcPadrao.upsert({ where: { idclienteAthos }, create: { idclienteAthos, emails: lista }, update: { emails: lista } })` -> devolve `{ idclienteAthos, emails: row.emails }`. Lista vazia faz upsert com `[]` (equivale a remover o padrão; um único caminho de escrita).
